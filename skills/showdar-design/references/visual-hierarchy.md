# Visual hierarchy

Hierarchy should communicate importance before decoration. Establish one dominant focal point, a clear reading order, and predictable levels for page title, section title, body, metadata, and actions. Use size, weight, spacing, position, and contrast together; do not solve hierarchy by adding more colors.

Dense tools need compact rhythm and aligned data. Editorial experiences can use larger type and whitespace. Mobile screens need fewer simultaneous hierarchy levels because viewport and attention are constrained.

Audit at 50% zoom or blurred view: the primary action, primary content, and major sections should still be obvious.
