# Project context audit

Discover the repository's canonical instruction, architecture, spec, glossary and ADR locations before proposing new files.

Evidence ledger columns: claim, source path, symbol/config, status (observed, supplied, inferred, unknown).

Propose only relevant docs/agents/*.md, preserving existing AGENTS.md or CLAUDE.md instructions.

Glossary bootstrap: derive terms from API schemas, models and user-confirmed language; for every candidate include definition, aliases and source. Ask approval before writing.

Never create an ADR based only on reading existing code. User-confirmed architectural choice and meaningful tradeoffs are required.
