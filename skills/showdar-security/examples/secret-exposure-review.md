# Secret exposure and configuration review

Inspect environment file names, CI configuration, source history when in scope, bundles, logs, crash reports, examples, and telemetry configuration. Output only locations, variable names, hashes, or counts that do not disclose values.

For a suspected exposure, state evidence status, affected credential or data boundary, rotation owner, blast radius, and verification needed. Treat rotation and revocation as explicit operational actions; do not silently change credentials.
