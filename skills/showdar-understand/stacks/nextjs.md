# Next.js repository signals

Inspect `app/` or `pages/`, route handlers, middleware, server/client boundaries, loading/error files, metadata, and deployment config. Locate data fetching and cache/revalidation ownership. Separate build-time, request-time, and browser-only code. Trace one route from URL to server handler/query to rendered output and one mutation back to invalidation. Check runtime selection and environment variable names without printing values.
