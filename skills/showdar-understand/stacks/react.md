# React repository signals

Locate the root render entry, route registry, context/provider composition, query/cache owner, and test setup. Distinguish server data, URL state, draft state, and derived render state. Follow imports from a route to its feature and from feature to API/client boundary. Check whether a component package is public through exports or only internal. Verify state ownership by tracing a user action through event handler, reducer/store, side effect, and rendered result.
