# CI/CD operations

Inspect existing workflows, package scripts, runners, permissions, caches, artifacts, environment bindings, and untrusted input. Compare CI commands with local canonical commands and report drift without changing the workflow in read-only mode.

For an explicit fix, make the smallest named change, keep tokens and secrets as references, validate syntax, and run the narrowest local check. Creating a new pipeline or widening permissions requires an explicit request and security review where trust boundaries change.
