# Observability

Use logs, metrics, traces, readiness/liveness/health checks, alerts, and dashboards only as evidence for the requested runtime decision. Verify useful identifiers, redaction, sampling, retention, and correlation without printing payloads or credentials.

For a rollout, define the signal, threshold from supplied policy, observation window, owner, and rollback action. Missing telemetry is a gap, not evidence that the service is healthy.
